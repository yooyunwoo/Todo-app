# 03: 완료 체크 / 되돌리기

**What to build:** 할 일 옆의 체크박스를 누르면 완료로 바뀌고, 다시 누르면 미완료로 돌아온다. 완료된 할 일은 제목에 취소선이 그어지고 흐린 색으로 보인다. 상태 변경은 서버 액션으로 처리하고 DB에 저장한다.

**Blocked by:** 02 (할 일 추가)

**Status:** ready-for-agent

- [ ] 체크박스를 누르면 완료가 되고, 제목에 취소선과 흐린 색이 적용된다
- [ ] 완료된 할 일을 다시 누르면 미완료로 돌아오고 취소선이 사라진다
- [ ] 체크해도 할 일의 목록 내 위치는 바뀌지 않는다 (최신순 유지)
- [ ] 새로고침해도 완료/미완료 상태가 유지된다
- [ ] 실패하면 짧은 안내가 보이고, 지금 화면의 목록은 그대로 남는다
