# 02: 할 일 추가

**What to build:** 방문자가 입력칸에 제목을 쓰고 추가 버튼을 누르거나 Enter를 치면, 새 할 일이 미완료 상태로 목록 맨 위에 생긴다. 추가는 서버 액션으로 처리한다. 다른 방문자도 새로고침하면 같은 할 일을 본다.

**Blocked by:** 01 (목록 보기)

**Status:** ready-for-agent

- [ ] 추가 버튼과 Enter 둘 다로 추가된다
- [ ] 제목 앞뒤 공백은 자동으로 지워진다
- [ ] 공백을 지운 뒤 비어 있으면 아무 일도 일어나지 않는다
- [ ] 제목은 최대 200자까지만 받는다 (입력칸과 서버 양쪽에서 막음)
- [ ] 같은 제목도 중복으로 추가된다
- [ ] 추가되면 입력칸이 비워지고, 처리 중에는 추가 버튼이 비활성화된다
- [ ] 새로 추가된 할 일은 미완료 상태이고 목록 맨 위에 나온다
- [ ] 새로고침해도 추가한 할 일이 남아 있다
- [ ] 추가에 실패하면 짧은 안내가 보이고, 지금 화면의 목록은 그대로 남는다
