# 01: 목록 보기 (DB 연결 + 빈 목록 화면)

**What to build:** 페이지를 열면 앱이 Turso DB에 접속해 하나뿐인 목록의 할 일을 최신순으로 보여 준다. `todos` 테이블(`id`, `title`, `done`, `created_at`)이 없으면 앱이 자동으로 만든다. 목록이 비어 있으면 안내 문구를 보여 준다. 접속 정보는 환경변수 `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`에서 읽고, DB 접속은 서버 쪽 코드 한 곳에서만 한다. 화면은 가운데 카드 한 장에 "할 일 목록" 제목이 있는 형태로, 휴대폰에서도 잘 보여야 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 처음 실행하면 `todos` 테이블이 없을 때 자동으로 생성된다 (Turso 웹에서 SQL을 직접 입력할 필요 없음)
- [ ] 목록이 비어 있으면 "할 일이 없어요. 하나 추가해 보세요."가 보인다
- [ ] 할 일이 있으면 최신순(새로 추가한 것이 맨 위)으로 보인다
- [ ] 환경변수가 빠지면 서버 로그에 빠진 변수 이름만 나오고, 값은 어디에도 출력되지 않는다
- [ ] DB 접속에 실패하면 화면에 "할 일을 불러오지 못했어요. 잠시 후 다시 시도해 주세요."만 보이고 자세한 오류나 토큰은 보이지 않는다
- [ ] DB 토큰이 브라우저로 전달되는 코드(클라이언트 컴포넌트, 공개 환경변수 등)가 없다
- [ ] 제목은 "할 일 목록"이고, 좁은 화면에서 가로 스크롤이 생기지 않는다
